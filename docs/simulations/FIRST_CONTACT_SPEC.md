- **Strict Simulation Boundaries**: Marked as synthetic (`is_synthetic: true`); zero access to production/external services.
- **Memory Namespace Isolation**: Inferences stored only in `mem:alien.<name>.v1`.

- **Fact vs Inference Segregation**: Clear distinction between simulated physical facts and entity interpretations.
